## Проект

PolyWorld — песочница бога (как WorldBox) + средневековая RTS эпохи чёрного
пороха (как Казаки, Stronghold). Godot 4.7, GDScript, Android-планшет
(Honor Pad 10), только касания, только одиночная игра. Полный дизайн —
`docs/RESEARCH.md`, текущее состояние — `docs/STATUS.md`. Прочитай оба перед работой.

## Главные правила

1. **Симуляция отдельно, картинка отдельно.** `sim/` — только данные и логика
   (массивы, словари, расчёты по тикам), без узлов отрисовки и без UI.
   `view/` и `ui/` только читают данные симуляции и шлют команды.
2. **Числа баланса — в `data/*.json`, не в коде.** Новый ресурс, здание или
   отряд — это запись в JSON + схема в `sim/defs.gd`.
3. **Время — только через `GameClock`.** Никаких своих таймеров для логики
   мира: подписывайся на `step`, `tick`, `day_passed`, `season_changed`.
   1 тик = 1 с при ×1, день = 60 тиков, сезон = 3 дня, год = 12 дней.
4. **Всё, что живёт в мире, сохраняется.** Новая система добавляет
   `to_dict()` / `from_dict()` и подключается в `sim/save_load.gd`.
   Сменил формат — подними `SAVE_VERSION` и допиши `_migrate()`.
5. **Тесты обязательны для `sim/`.** Новый код симуляции — новый
   `tests/test_*.gd`. Перед коммитом: `tools/run_tests.sh` — все зелёные.
6. **Планшет.** Рендерер Compatibility, кнопки не меньше 48×48 (лучше 64+),
   фильтр Nearest, базовое окно 1280×800, никаких наведений мыши.
7. **Понятные ошибки.** Сообщение об ошибке в данных называет файл и поле.
   Тексты для игрока — на русском.

## Структура

| Папка | Что там |
| --- | --- |
| `sim/` | симуляция и автозагрузки: GameClock, Defs, SaveLoad |
| `view/` | отрисовка мира (сейчас — заглушка) |
| `ui/` | меню, панели, отладочная панель, тема |
| `data/` | JSON с балансом: resources.json, biomes.json |
| `assets/` | спрайты, звуки, шрифты |
| `tests/` | тесты, `run_tests.gd` — раннер без окна |
| `tools/` | скрипты для разработки (генераторы спрайтов, запуск тестов) |
| `docs/` | RESEARCH.md (дизайн), STATUS.md (что сделано) |

## Команды

```sh
godot --headless --path . --import                       # первый импорт
godot --headless --path . -s res://tests/run_tests.gd    # тесты
tools/run_tests.sh                                       # то же одной командой
```

## Стиль кода

- GDScript со статической типизацией там, где тип известен.
- Табы для отступов, `snake_case` для функций и переменных, `PascalCase` для классов.
- Комментарий `##` в начале каждого файла: что это и зачем.
- Маленькие этапы: каждый заканчивается сборкой, которая запускается на
  планшете. В конце этапа обнови `docs/STATUS.md`.
