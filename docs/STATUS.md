# Состояние проекта

Версия **0.1.0** · этап 0 «Каркас проекта» сделан · Godot 4.7.2

## Сделано

**Проект Godot 4.7** (`project.godot`)
- рендерер Compatibility (и для ПК, и для мобильных);
- базовое окно 1280×800, растяжение `canvas_items` + `expand`;
- ориентация «альбомная по датчику»: только альбомная, но переворачивается вместе с планшетом;
- фильтр текстур Nearest по умолчанию; тема `ui/theme.tres` (шрифт 22);
- пресет экспорта Android (`export_presets.cfg`): arm64-v8a, пакет `com.paylo22.polyworld`, полноэкранный режим; в сборку входят `data/*.json`, не входят `tests/`, `tools/`, `docs/`.

**Папки:** `sim/`, `view/`, `ui/`, `data/`, `assets/`, `tests/`, `docs/`, `tools/`.

**Автозагрузки**

| Имя | Файл | Что делает |
| --- | --- | --- |
| `GameClock` | `sim/game_clock.gd` | шаг 0,1 с; тик = 10 шагов; день = 60 тиков; сезон = 3 дня; год = 12 дней. Пауза, ×1, ×2, ×5 — меняется число шагов за кадр, длина шага постоянна. Сигналы `step`, `tick`, `day_passed`, `season_changed`, `year_passed`, `paused_changed`, `speed_changed`. Замер мс на шаг. `to_dict` / `from_dict` |
| `Defs` | `sim/defs.gd` + `sim/schema.gd` | читает `data/resources.json` и `data/biomes.json`, проверяет по схеме и перекрёстным ссылкам. Ошибка называет файл, строку (для синтаксиса) и путь к полю, например `data/resources.json: resources[1] «flour».tipe — неизвестное поле (опечатка?)` |
| `SaveLoad` | `sim/save_load.gd` | один файл `user://saves/save.json` с полем `version`; запись через временный файл; отказ на сохранениях новее игры |
| `DebugOverlay` | `ui/debug_overlay.tscn` | отладочная панель (см. ниже) |

**Данные** (по таблицам из RESEARCH.md)
- `resources.json` — 6 хранилищ (амбар 400, склад 500, арсенал 200, пороховой погреб 150, конюшня, казна без предела) и 27 ресурсов. «Пиво / вино» и «Шерсть / ткань» разделены на отдельные ресурсы.
- `biomes.json` — 8 биомов: ресурсы, природные особенности (дичь, пашня, торф…), лучший материал стройки, цвет пикселя карты (черновой). Вода — это высота < 0, а не биом.
- Ключи, начинающиеся с `_`, — комментарии, проверка их пропускает.

**Экраны**
- Главное меню (`ui/main_menu.tscn`): «Новый мир», «Загрузить» (неактивна, пока нет сохранения), версия в углу. При ошибке в данных показывает её красным текстом и не пускает в игру.
- Заглушка экрана мира (`view/world_placeholder.tscn`): дата, «Сохранить», «В меню». Карта появится на этапе 1.
- Отладочная панель: FPS, мс на шаг симуляции и шагов в секунду, дата, сезон, номер тика, кнопки «Пуск/Пауза», ×1, ×2, ×5. Касание тремя пальцами (на ПК — F3) открывает и закрывает.

**Тесты** — `tests/run_tests.gd`, 32 теста: часы (14), данные (14), сохранение (4). Все проходят на Godot 4.7.2 (Linux, без окна). Запуск: `tools/run_tests.sh`.

## Как устроено

- Логика часов — в `GameClock.advance(секунды)`: копит время, делает целое число шагов, за кадр не больше 100 (если кадр был очень долгим, игра замедляется, а не зависает). Тесты зовут `advance` напрямую, без дерева сцен.
- Схема данных описана словарями в `sim/defs.gd`; проверку делает `sim/schema.gd`. При любой ошибке данные не загружаются вовсе, `Defs.is_ok()` — false.
- Раннер тестов ищет `tests/test_*.gd`, вызывает методы `test_*`; если тест-файл не разбирается, раннер всё равно завершается с кодом 1, а не зависает.

## Проверка на планшете

1. Открыть проект в Godot 4.7, запустить — главное меню, справа внизу «версия 0.1.0».
2. «Загрузить» неактивна (сохранений ещё нет).
3. «Новый мир» → экран с датой «Год 1, Весна, день 1», дата начинает идти.
4. Коснуться экрана тремя пальцами → слева вверху отладочная панель с FPS и мс на шаг.
5. Нажать ×5 → день меняется каждые 12 секунд, сезон — каждые 36 (после «день 3» идёт «Лето»).
6. «Пауза» → дата стоит. «Пуск» → снова идёт.
7. «Сохранить» → «В меню» → «Загрузить» → та же дата.
8. Снова три пальца → панель скрылась.
