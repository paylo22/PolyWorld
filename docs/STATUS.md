# Статус проекта

Версия **0.1.0** · этап 0 «Каркас» · ноябрь 2026 · Godot 4.7.2

## Что есть

**Проект Godot 4.7** (`project.godot`)
- рендерер Compatibility (и для ПК, и для мобильных);
- окно 1280×800, растяжение `canvas_items` + `expand`;
- ориентация «альбомная по датчику» (sensor landscape): только альбомная, но переворачивается вместе с планшетом;
- фильтр текстур Nearest по умолчанию;
- тема `ui/theme.tres` (шрифт 22);
- пресет экспорта Android (`export_presets.cfg`): arm64-v8a, пакет `com.paylo22.polyworld`, полноэкранный режим, в сборку включаются `data/*.json`, не включаются `tests/`, `tools/`, `docs/`.

**Автозагрузки**

| Имя | Файл | Что делает |
| --- | --- | --- |
| `GameClock` | `sim/game_clock.gd` | шаги (10 на тик), тики (1 с при ×1), дни (60 тиков), сезоны (3 дня), годы (12 дней); пауза; скорости ×1, ×2, ×5; сигналы `step`, `tick`, `day_passed`, `season_changed`, `year_passed`, `paused_changed`, `speed_changed`; замер мс на шаг; `to_dict` / `from_dict` |
| `Defs` | `sim/defs.gd` + `sim/schema.gd` | читает `data/resources.json` и `data/biomes.json`, проверяет по схеме и перекрёстным ссылкам; ошибка называет файл, строку (для синтаксиса) и путь к полю |
| `SaveLoad` | `sim/save_load.gd` | один файл `user://save.json` с полем `version`; запись через временный файл; отказ на сохранениях новее игры |
| `DebugOverlay` | `ui/debug_overlay.tscn` | отладочная панель (см. ниже) |

**Данные** (по таблицам из RESEARCH.md)
- `resources.json` — 6 хранилищ (амбар 400, склад 500, арсенал 200, пороховой погреб 150, конюшня, казна без предела) и 27 ресурсов. «Пиво / вино» и «Шерсть / ткань» разделены на отдельные ресурсы.
- `biomes.json` — 8 биомов с ресурсами, природными особенностями (дичь, пашня, торф…), лучшим материалом стройки и цветом пикселя карты (цвета черновые). Вода — это высота < 0, а не биом.

**Экраны**
- Главное меню (`ui/main_menu.tscn`): «Новый мир», «Загрузить» (неактивна, пока нет сохранения), версия в углу. При ошибке в данных показывает её красным текстом и не пускает в игру.
- Заглушка мира (`view/world_placeholder.tscn`): дата, «Сохранить», «В меню». Карты пока нет.
- Отладочная панель: FPS, мс на шаг симуляции и шагов в секунду, дата, сезон, номер тика, кнопки «Пуск/Пауза», ×1, ×2, ×5. Касание тремя пальцами (на ПК — F3) открывает и закрывает.

**Тесты** — `tests/run_tests.gd`, 32 теста: часы (14), данные (14), сохранение (4). Все проходят на Godot 4.7.2 (Linux, без окна).

## Как проверить на планшете

1. Открыть проект в Godot 4.7, запустить.
2. «Новый мир» → коснуться экрана тремя пальцами → появится панель.
3. Нажать ×5: день сменяется каждые 12 секунд, сезон каждые 36 секунд.
4. «Пауза» → дата стоит. «Сохранить» → «В меню» → «Загрузить» → дата та же.

## Как запустить тесты

```sh
tools/run_tests.sh
# или
godot --headless --path . -s res://tests/run_tests.gd
```

Строка `ERROR: GameClock.set_speed: недопустимая скорость 3` в выводе — это нормально: тест специально проверяет, что неверная скорость отклоняется.
